# Contributing

## Development Rules

Read `AGENTS.md` and `.agents/BASELINE.md` before making changes. Keep changes focused, typed, tested, and documented. Do not add personal data, secrets, browser profiles, or generated job results.

## Change Expectations

- Add tests for new behavior.
- Update relevant documentation for user-visible changes.
- Keep source integrations isolated.
- Run the project's configured format, lint, type, and test commands.
- Leave commits and publishing to the repository owner.

## Sensitive Test Data

Use synthetic or sanitized fixtures. The maintainer's local resume is not a repository fixture and must not be copied into tests or examples.
